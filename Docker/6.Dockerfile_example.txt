## 🔹 Sample Dockerfile (Node.js Application)

```dockerfile
# Use official Node.js image as base (contains OS + Node installed)
FROM node:18

# Set working directory inside container
# All next commands will run from /app
WORKDIR /app

# Copy only package.json first
# (Done separately to take advantage of Docker layer caching)
COPY package.json .

# Install dependencies inside container
# RUN executes during build time and creates a new layer
RUN npm install

# Copy remaining application code from local machine to container
COPY . .

# Expose port 3000 (only for documentation, does NOT open port)
EXPOSE 3000

# Set environment variable inside container
ENV NODE_ENV=production

# Default command to run when container starts
# CMD runs at container runtime (not build time)
CMD ["node", "app.js"]
```

---

# 🔹 Line-by-Line Explanation (Simple)

### 🔸 `FROM node:18`

👉 Base image with Node.js installed
👉 Everything builds on top of this

---

### 🔸 `WORKDIR /app`

👉 Sets `/app` as working directory
👉 Same as doing `cd /app`

---

### 🔸 `COPY package.json .`

👉 Copies only `package.json` first
👉 Helps in **caching dependencies**

---

### 🔸 `RUN npm install`

👉 Installs dependencies during build
👉 Creates a new image layer

---

### 🔸 `COPY . .`

👉 Copies full project code
👉 Done after install to avoid reinstalling every time

---

### 🔸 `EXPOSE 3000`

👉 Tells container listens on port 3000
👉 Used for documentation only

---

### 🔸 `ENV NODE_ENV=production`

👉 Sets environment variable inside container

---

### 🔸 `CMD ["node", "app.js"]`

👉 Runs app when container starts
👉 Can be overridden during `docker run`

---

# 🔹 How to Build and Run

### ✅ Build Image:

```bash
docker build -t mynodeapp:1.0 .
```

---

### ✅ Run Container:

```bash
docker run -p 3000:3000 mynodeapp:1.0
```

👉 Access app at:

```
http://localhost:3000
```

---

# 🔹 Interview Tips from this Dockerfile 🔥

* `COPY package.json` first → **Layer caching optimization**
* `RUN npm install` → **Build-time execution**
* `CMD` → **Runtime execution**
* `EXPOSE` → **Only documentation**
* `WORKDIR` → Avoids multiple `cd`
