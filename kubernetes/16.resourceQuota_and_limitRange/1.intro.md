# Limiting Namespace Quotas in Kubernetes

You can control resource usage in a namespace using **ResourceQuota** and **LimitRange** objects.

## 1. ResourceQuota (Namespace-level limits)

Restricts total resources that can be consumed by all pods in a namespace.

**Example:**
```yaml
apiVersion: v1
kind: ResourceQuota
metadata:
  name: compute-quota
  namespace: my-namespace
spec:
  hard:
    requests.cpu: "10"           # Total CPU requests
    requests.memory: "20Gi"      # Total memory requests
    limits.cpu: "20"             # Total CPU limits
    limits.memory: "40Gi"        # Total memory limits
    pods: "100"                  # Max number of pods
    services: "10"               # Max services
    persistentvolumeclaims: "5"  # Max PVCs
```

**Apply it:**
```bash
kubectl apply -f resourcequota.yaml
kubectl get resourcequota -n my-namespace
kubectl describe resourcequota compute-quota -n my-namespace
```

## 2. LimitRange (Per-container/pod limits)

Sets min/max resource limits for individual containers and pods.

**Example:**
```yaml
apiVersion: v1
kind: LimitRange
metadata:
  name: cpu-memory-limits
  namespace: my-namespace
spec:
  limits:
  - max:
      cpu: "2"              # Max CPU per container
      memory: "4Gi"         # Max memory per container
    min:
      cpu: "100m"           # Min CPU per container
      memory: "128Mi"       # Min memory per container
    type: Container
  
  - max:
      cpu: "4"              # Max total CPU per pod
      memory: "8Gi"         # Max total memory per pod
    min:
      cpu: "200m"
      memory: "256Mi"
    type: Pod
```

**Apply it:**
```bash
kubectl apply -f limitrange.yaml
kubectl get limitrange -n my-namespace
```

## 3. Complete Example Setup

```bash
# Create namespace
kubectl create namespace my-namespace

# Apply ResourceQuota
kubectl apply -f - <<EOF
apiVersion: v1
kind: ResourceQuota
metadata:
  name: app-quota
  namespace: my-namespace
spec:
  hard:
    requests.cpu: "50"
    requests.memory: "100Gi"
    limits.cpu: "100"
    limits.memory: "200Gi"
    pods: "200"
EOF

# Apply LimitRange
kubectl apply -f - <<EOF
apiVersion: v1
kind: LimitRange
metadata:
  name: app-limits
  namespace: my-namespace
spec:
  limits:
  - max:
      cpu: "4"
      memory: "8Gi"
    min:
      cpu: "100m"
      memory: "128Mi"
    type: Container
  - max:
      cpu: "8"
      memory: "16Gi"
    type: Pod
EOF

# Verify
kubectl get quota,limits -n my-namespace
```

## 4. Check Usage vs Quota

```bash
kubectl describe resourcequota app-quota -n my-namespace
```

Output shows:
```
Resource                 Requests    Limits
--------                 --------    ------
requests.cpu             20/50       40/100
requests.memory          30Gi/100Gi  60Gi/200Gi
pods                     15/200
```

## Key Differences

| Feature | ResourceQuota | LimitRange |
|---------|---------------|-----------|
| **Scope** | Namespace total | Per container/pod |
| **Controls** | Total consumption | Individual limits |
| **Enforces** | Quota exceeded = pods rejected | Min/max boundaries |

**Best practice:** Use both together — ResourceQuota for namespace budgets, LimitRange to prevent single pods from consuming everything.
