## Helm template functions inside `{{ ... }}` (placeholders)

Inside Helm placeholders, you can use **functions** to modify values, format YAML, validate inputs, or apply logic.

General syntax:

```yaml
{{ FUNCTION ARGUMENTS }}
```

or with **pipeline** (most common):

```yaml
{{ VALUE | FUNCTION }}
```

Think of `|` as: **“take this value, then apply this function.”**

---

# 1. Default function → `default`

Use when a value may be missing.

### Syntax

```yaml
{{ .Values.name | default "guest" }}
```

### Example

**values.yaml**

```yaml
# name not provided
```

**template**

```yaml
user: {{ .Values.name | default "guest" }}
```

**Output**

```yaml
user: guest
```

**Use case:** fallback value

---

# 2. Required function → `required`

Make a value mandatory.

### Syntax

```yaml
{{ required "name is required" .Values.name }}
```

### Example

```yaml
image: nginx:{{ required "tag required" .Values.tag }}
```

If missing:

```text
Error: tag required
```

**Use case:** stop deployment if important value missing

---

# 3. Quote function → `quote`

Wrap value in quotes.

### Example

```yaml
env: {{ .Values.environment | quote }}
```

If:

```yaml
environment: prod
```

Output:

```yaml
env: "prod"
```

**Use case:** safer YAML strings

---

# 4. Upper / Lower / Title

Change text case.

```yaml
{{ "hello" | upper }}
```

Output:

```text
HELLO
```

```yaml
{{ "HELLO" | lower }}
```

Output:

```text
hello
```

```yaml
{{ "hello world" | title }}
```

Output:

```text
Hello World
```

---

# 5. Replace

Replace text.

```yaml
{{ "my-app" | replace "-" "_" }}
```

Output:

```text
my_app
```

---

# 6. Trim

Remove spaces.

```yaml
{{ " hello " | trim }}
```

Output:

```text
hello
```

---

# 7. Indent

Add spaces to **each line**.

```yaml
summary: {{ "hello\nworld" | indent 2 }}
```

Output:

```yaml
summary:   hello
  world
```

---

# 8. Nindent

**Newline + indent**

```yaml
summary:{{ "hello\nworld" | nindent 2 }}
```

Output:

```yaml
summary:
  hello
  world
```

Most common for YAML blocks.

---

# 9. ToYaml

Convert object/list to YAML.

### values.yaml

```yaml
labels:
  app: nginx
  env: prod
```

### template

```yaml
metadata:
  labels:{{ .Values.labels | toYaml | nindent 4 }}
```

### Output

```yaml
metadata:
  labels:
    app: nginx
    env: prod
```

Very important in Helm.

---

# 10. ToJson

Convert to JSON.

```yaml
{{ .Values.labels | toJson }}
```

Output:

```json
{"app":"nginx","env":"prod"}
```

---

# 11. Len

Get length.

```yaml
{{ len .Values.items }}
```

If list has 3 items:

```text
3
```

---

# 12. Join

Join list into string.

### values.yaml

```yaml
items:
  - apple
  - mango
```

### template

```yaml
{{ .Values.items | join "," }}
```

Output:

```text
apple,mango
```

---

# 13. Split

Split string into list.

```yaml
{{ "a,b,c" | split "," }}
```

---

# 14. printf

Format strings.

```yaml
{{ printf "%s-%s" "app" "prod" }}
```

Output:

```text
app-prod
```

---

# 15. Include

Call another template.

```yaml
{{ include "mychart.fullname" . }}
```

Used for reusable template snippets.

---

# 16. tpl

Render a string as template.

If value contains template syntax itself.

Advanced usage.

---

# 17. If condition

```yaml
{{ if .Values.enabled }}
enabled
{{ end }}
```

---

# 18. Range loop

Loop through list.

```yaml
{{ range .Values.items }}
- {{ . }}
{{ end }}
```

---

# 19. With

Change current context.

```yaml
{{ with .Values.image }}
repo: {{ .repository }}
{{ end }}
```

---

# Interview quick summary

| Function      | Purpose                 |
| ------------- | ----------------------- |
| `default`     | Fallback value          |
| `required`    | Mandatory value         |
| `quote`       | Add quotes              |
| `upper/lower` | Change case             |
| `replace`     | Replace text            |
| `trim`        | Remove spaces           |
| `indent`      | Add spaces              |
| `nindent`     | Newline + spaces        |
| `toYaml`      | Convert to YAML         |
| `toJson`      | Convert to JSON         |
| `len`         | Count items             |
| `join`        | Merge list              |
| `split`       | Split string            |
| `printf`      | Format string           |
| `include`     | Reuse template          |
| `tpl`         | Render dynamic template |
| `if`          | Conditional             |
| `range`       | Loop                    |
| `with`        | Change scope            |

### Most commonly used daily:

```yaml
{{ .Values.name | default "app" }}
{{ required "tag required" .Values.tag }}
{{ .Values.labels | toYaml | nindent 4 }}
{{ include "chart.fullname" . }}
```
