NodePort is where Kubernetes first exposes your app **outside the cluster** without needing a cloud load balancer. Let’s go deep in the same **interview + real-world + flow-based** style.

---

# 🚀 NodePort Service (Complete Guide)

---

# 1. What is NodePort?

## Definition

A **NodePort Service** exposes your application on a **static port on every node’s IP**.

---

## Key Idea

```text
<NodeIP>:<NodePort> → Service → Pods
```

---

# 2. Why NodePort?

ClusterIP:

* Internal only ❌

NodePort:

* External access ✔
* Simple exposure ✔

---

# 3. Basic YAML

```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-nodeport
spec:
  type: NodePort
  selector:
    app: my-app
  ports:
  - port: 80
    targetPort: 80
    nodePort: 30007
```

---

# 4. YAML Fields Explained

---

## 🔹 type

```yaml
type: NodePort
```

👉 Enables external access

---

## 🔹 ports

```yaml
ports:
- port: 80
  targetPort: 80
  nodePort: 30007
```

---

### Meaning

| Field      | Meaning       |
| ---------- | ------------- |
| port       | Service port  |
| targetPort | Pod port      |
| nodePort   | External port |

---

## 🔥 NodePort Range

```text
30000 – 32767
```

---

# 5. How NodePort Works Internally

---

## Key Components

* kube-proxy
* iptables / IPVS
* Node network

---

## Internal Mapping

```text
<NodeIP>:NodePort → ClusterIP → Pod
```

---

# 6. Request Flow (VERY IMPORTANT 🔥)

---

## Step-by-step Flow

```text
User (Browser)
   ↓
Node IP + NodePort
   ↓
kube-proxy (iptables rules)
   ↓
ClusterIP (Service)
   ↓
Pod IP (Load balanced)
```

---

## Full Flow Example

```text
http://192.168.1.10:30007
         ↓
Node receives request
         ↓
kube-proxy redirects to Service
         ↓
Service forwards to Pod (80)
         ↓
Response back to client
```

# 10. Difference from ClusterIP

| Feature  | ClusterIP     | NodePort         |
| -------- | ------------- | ---------------- |
| Access   | Internal      | External         |
| Port     | Cluster only  | Node port        |
| Use case | Microservices | External testing |

---

# 11. NodePort vs LoadBalancer

| Feature     | NodePort | LoadBalancer |
| ----------- | -------- | ------------ |
| Setup       | Manual   | Automatic    |
| External IP | Node IP  | Cloud LB     |
| Production  | ❌        | ✔            |
