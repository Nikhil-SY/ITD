# 🚀 ReplicaSet in Kubernetes (Complete Guide)

---

# 1. What is a ReplicaSet?

## Definition

A **ReplicaSet (RS)** ensures that a specified number of **Pod replicas** are running at all times.

👉 It is responsible for:

* Maintaining desired number of Pods
* Replacing failed Pods
* Scaling Pods

---

# 2. Why ReplicaSet?

Without ReplicaSet:
❌ Pods die → not recreated
❌ No scaling
❌ No self-healing

With ReplicaSet:
✔ Auto-healing
✔ Scaling
✔ High availability

---

# 3. Architecture

```
ReplicaSet
   ↓
Pods
   ↓
Containers
```

---

# 4. Basic ReplicaSet YAML

```yaml
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: nginx-rs
  labels:
    app: nginx
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.25
```
