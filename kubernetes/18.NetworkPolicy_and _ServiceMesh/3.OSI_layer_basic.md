# OSI Model — In-Depth Functionality of Each Layer

The OSI model is not just theory.
Each layer performs a **specific responsibility** so communication happens reliably between systems.

Think of it like:

* Every layer adds its own information
* Each layer talks only to its peer layer on the destination
* Data moves:

  * Downward while sending → **Encapsulation**
  * Upward while receiving → **De-encapsulation**

---

# Complete OSI Stack

| Layer | Name         | Main Responsibility            |
| ----- | ------------ | ------------------------------ |
| 7     | Application  | User-facing network services   |
| 6     | Presentation | Data formatting, encryption    |
| 5     | Session      | Session management             |
| 4     | Transport    | Reliable communication         |
| 3     | Network      | Routing and logical addressing |
| 2     | Data Link    | Local delivery using MAC       |
| 1     | Physical     | Actual signal transmission     |

---

# Layer 7 — Application Layer

## Main Purpose

Provides network services directly to applications/users.

This is where:

* Browser
* Mobile apps
* APIs
* Email clients

interact with the network.

---

# Core Functionalities

## 1. User Interaction

Allows applications to access network resources.

Example:

* Chrome accessing Google
* Curl calling API
* Outlook sending mail

## 2. Protocol Handling

# Layer 6 — Presentation Layer

## Main Purpose

Makes sure data is:

* Readable
* Secure
* Properly formatted

This layer acts as a **translator**.

---

# Core Functionalities

## 1. Encryption

Most important functionality.

Example:

* HTTPS uses TLS/SSL

Plain text:

```text id="3pd0x0"
password=admin123
```

Encrypted into ciphertext.

---

## 2. Decryption

Destination reverses encryption.

---

## 3. Data Compression

Reduces bandwidth usage.

Example:

* ZIP
* GZIP
* Video compression

---

## 4. Data Translation

Different systems may use different formats.

Converts:

* ASCII
* Unicode
* JSON
* XML

---

# Real Example

Browser sends:

```json id="nq7ph9"

```

Presentation layer:

* Encodes UTF-8
* Encrypts TLS
* Compresses if needed

# Layer 4 — Transport Layer

## Main Purpose

Provides:

* End-to-end delivery
* Reliability
* Flow control
* Error handling

---

# Core Functionalities

# 1. Segmentation

Large data divided into smaller chunks.

Example:

```text id="zuwyyd"
100 MB file
```

split into multiple TCP segments.

---

# 2. Port Addressing

Uses port numbers.

| Service | Port |
| ------- | ---- |

| MySQL   | 3306 |

# 3. Reliability (TCP)

* Ordered delivery

---

# 4. Flow Control

Prevents receiver overload.

TCP windowing mechanism controls speed.

---

# 5. Error Detection

Checksum validation.

## Layer 2 vs Layer 3

| Layer 2       | Layer 3       |
| ------------- | ------------- |
| MAC Address   | IP Address    |
| Switch        | Router        |
| Local network | Inter-network |

## TCP vs UDP

| TCP           | UDP                   |
| ------------- | --------------------- |
| Reliable      | Fast                  |
| Handshake     | No handshake          |
| Ordered       | Unordered             |
| Used in HTTPS | Used in DNS/Streaming |
