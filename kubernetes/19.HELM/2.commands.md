## Common Helm Commands and Their Usage

Helm = **Kubernetes package manager**
It helps you **install, upgrade, rollback, and manage applications** using **charts**.

---

# 1. Create a new Helm chart

### Command

```bash
helm create <chart-name>
```

### Example

```bash
helm create myapp
```

### Usage

Creates boilerplate chart structure:

```text
myapp/
 ├── Chart.yaml
 ├── values.yaml
 ├── charts/
 └── templates/
```

---

# 2. Validate chart syntax

### Command

```bash
helm lint <chart-path>
```

### Example

```bash
helm lint .
```

### Usage

Checks:

* YAML syntax
* Template errors
* Best practices

Use before deploying.

---

# 3. Render templates locally (dry run)

### Command

```bash
helm template <release-name> <chart-path>
```

### Example

```bash
helm template myapp .
```

### Usage

Shows generated Kubernetes YAML **without installing**.

Useful for:

* debugging templates
* checking variable substitution

---

# 4. Install a chart

### Command

```bash
helm install <release-name> <chart>
```

### Example

```bash
helm install myapp .
```

### Usage

Deploys application to Kubernetes.

* **release-name** = instance name
* **chart** = chart path/repo chart

---

# 5. List installed releases

### Command

```bash
helm list
```

### Usage

Shows installed Helm releases.

Example output:

```text
NAME    NAMESPACE   STATUS
myapp   default     deployed
```

---

# 6. Check release status

### Command

```bash
helm status <release-name>
```

### Example

```bash
helm status myapp
```

### Usage

Shows:

* deployment status
* resources created
* notes

---

# 7. Upgrade existing release

### Command

```bash
helm upgrade <release-name> <chart>
```

### Example

```bash
helm upgrade myapp .
```

### Usage

Apply chart changes without reinstalling.

---

# 8. Upgrade with new values

### Command

```bash
helm upgrade <release-name> <chart> -f values.yaml
```

### Example

```bash
helm upgrade myapp . -f prod-values.yaml
```

### Usage

Deploy using custom values.

---

# 9. Dry-run installation/upgrade

### Command

```bash
helm install myapp . --dry-run
```

or

```bash
helm upgrade myapp . --dry-run
```

### Usage

Simulates deployment without applying changes.

---

# 10. Show release history

### Command

```bash
helm history <release-name>
```

### Example

```bash
helm history myapp
```

### Usage

Shows all revisions.

---

# 11. Rollback to previous version

### Command

```bash
helm rollback <release-name> <revision>
```

### Example

```bash
helm rollback myapp 1
```

### Usage

Restore earlier deployment.

---

# 12. Uninstall release

### Command

```bash
helm uninstall <release-name>
```

### Example

```bash
helm uninstall myapp
```

### Usage

Deletes deployed application.

---

# 13. Search charts in repositories

### Command

```bash
helm search repo <chart-name>
```

### Example

```bash
helm search repo nginx
```

### Usage

Find charts from added repos.

---

# 14. Add Helm repository

### Command

```bash
helm repo add <name> <repo-url>
```

### Example

```bash
helm repo add bitnami https://charts.bitnami.com/bitnami
```

### Usage

Adds external chart repository.

---

# 15. Update repositories

### Command

```bash
helm repo update
```

### Usage

Refresh latest chart versions.

---

# 16. Download chart without installing

### Command

```bash
helm pull <chart>
```

### Example

```bash
helm pull bitnami/nginx
```

### Usage

Downloads chart package locally.

---

# 17. Package your chart

### Command

```bash
helm package <chart-folder>
```

### Example

```bash
helm package myapp
```

### Usage

Creates `.tgz` distributable package.

---

# Interview quick summary

| Command            | Purpose              |
| ------------------ | -------------------- |
| `helm create`      | Create chart         |
| `helm lint`        | Validate chart       |
| `helm template`    | Render YAML locally  |
| `helm install`     | Deploy chart         |
| `helm list`        | View releases        |
| `helm status`      | Check release        |
| `helm upgrade`     | Update deployment    |
| `helm history`     | Show revisions       |
| `helm rollback`    | Revert changes       |
| `helm uninstall`   | Delete release       |
| `helm repo add`    | Add chart repo       |
| `helm repo update` | Refresh repos        |
| `helm search repo` | Search charts        |
| `helm package`     | Create chart package |

### Most used daily:

```bash
helm lint .
helm template myapp .
helm install myapp .
helm upgrade myapp .
helm list
helm uninstall myapp
```
