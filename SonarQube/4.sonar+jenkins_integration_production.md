# 🔹 1. Setup 1: **Separate Server Architecture (Production Standard)**

---

## 🔹 Architecture

```text
EC2-1 → Jenkins
EC2-2 → SonarQube + PostgreSQL
```

👉 Why separate?

* Better performance
* Better security
* Scalable

---

## 🔹 Step-by-Step

---

### 🔸 Step 1: Launch 2 EC2 Instances

#### EC2-1 (Jenkins)

* Port: 8080

#### EC2-2 (SonarQube)

* Port: 9000

---

### 🔸 Step 2: Security Groups

#### SonarQube EC2

| Port | Source         |
| ---- | -------------- |
| 9000 | Jenkins EC2 IP |
| 22   | Your IP        |

👉 Restrict access (best practice)

---

### 🔸 Step 3: Install SonarQube on EC2-2

👉 Same steps you did earlier:

* Java
* PostgreSQL
* SonarQube setup

---

### 🔸 Step 4: Access SonarQube

```text
http://<Sonar-EC2-IP>:9000
```

---

### 🔸 Step 5: Generate Token

* SonarQube → My Account → Security
* Create token

---

### 🔸 Step 6: Configure Jenkins (EC2-1)

---

#### Add SonarQube

👉 Manage Jenkins → Configure System

* Name: `sonarqube`
* URL:

```text
http://<Sonar-EC2-IP>:9000
```

---

#### Add Token

* Credentials → Secret Text

---

### 🔸 Step 7: Test Connection

👉 In Jenkins:

* Test SonarQube connection → should succeed

---

## 🔹 Flow

```text
Jenkins → SonarQube (via API) → DB
```

---

## 🔹 Pros

* Scalable
* Secure
* Used in enterprises

---

## 🔹 Cons

* More setup effort

# 🔹 2. Setup 2: **Docker-Based SonarQube (Fast & Easy)**

---

## 🔹 Architecture

```text
Single EC2 → Docker → SonarQube Container + PostgreSQL Container
```

---

## 🔹 Step-by-Step

---

### 🔸 Step 1: Launch EC2

* Ubuntu
* t3.medium
* Open port 9000

---

### 🔸 Step 2: Install Docker

```bash
sudo apt update
sudo apt install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
```

---

### 🔸 Step 3: Run PostgreSQL Container

```bash
docker run -d --name postgres \
  -e POSTGRES_USER=sonar \
  -e POSTGRES_PASSWORD=sonar123 \
  -e POSTGRES_DB=sonarqube \
  postgres
```

---

### 🔸 Step 4: Run SonarQube Container

```bash
docker run -d --name sonarqube \
  -p 9000:9000 \
  --link postgres \
  -e SONAR_JDBC_URL=jdbc:postgresql://postgres:5432/sonarqube \
  -e SONAR_JDBC_USERNAME=sonar \
  -e SONAR_JDBC_PASSWORD=sonar123 \
  sonarqube:lts
```

---

### 🔸 Step 5: Access Dashboard

```text
http://<EC2-IP>:9000
```

---

### 🔸 Login

* admin / admin

---

## 🔹 Optional: Docker Compose (Better)

---

### 🔸 docker-compose.yml

```yaml
version: "3"

services:
  db:
    image: postgres
    environment:
      POSTGRES_USER: sonar
      POSTGRES_PASSWORD: sonar123
      POSTGRES_DB: sonarqube

  sonarqube:
    image: sonarqube:lts
    ports:
      - "9000:9000"
    environment:
      SONAR_JDBC_URL: jdbc:postgresql://db:5432/sonarqube
      SONAR_JDBC_USERNAME: sonar
      SONAR_JDBC_PASSWORD: sonar123
    depends_on:
      - db
```

---

### 🔸 Run

```bash
docker-compose up -d
```

---

## 🔹 Pros

* Very fast setup
* Easy to manage
* Good for testing

---

## 🔹 Cons

* Not ideal for large production
* Needs tuning for persistence
