Below is a **complete end-to-end SonarQube + Jenkins pipeline** with **every step explained**—from zero setup to a working CI pipeline with **Quality Gate enforcement**.

# 🔹 1. High-Level Flow (Understand First)

```text
Git Push → Jenkins Trigger → Build → Sonar Analysis → Quality Gate → Deploy
```

---

# 🔹 2. Prerequisites (Must Have)

* Jenkins installed & running
* SonarQube server running (port 9000)
* Java/Maven project (or any supported language)
* Git repository

---

# 🔹 3. Step-by-Step Jenkins Setup

---

## 🔸 STEP 1: Install Required Plugins

👉 Go to:
**Manage Jenkins → Plugins → Available**

Install:

* ✅ SonarQube Scanner
* ✅ Pipeline
* ✅ Git
* ✅ Maven Integration

---

## 🔸 STEP 2: Add SonarQube Server in Jenkins

👉 Go to:
**Manage Jenkins → Configure System**

### Add SonarQube:

* Name: `sonarqube`
* Server URL:

  ```
  http://<SONAR-IP>:9000
  ```

---

## 🔸 STEP 3: Create Sonar Token

👉 In SonarQube UI:

* Go to:

  ```
  My Account → Security → Generate Token
  ```

Example:

```text
sonar-token-xyz123
```

---

## 🔸 STEP 4: Add Token in Jenkins Credentials

👉 Go to:
**Manage Jenkins → Credentials**

* Kind: **Secret Text**
* ID: `sonar-token`
* Secret: paste token

---

## 🔸 STEP 5: Link Token to SonarQube

Back to:

👉 **Manage Jenkins → Configure System**

* Under SonarQube:

  * Select credentials → `sonar-token`

---

## 🔸 STEP 6: Configure Sonar Scanner Tool

👉 Go to:
**Manage Jenkins → Global Tool Configuration**

Add:

* SonarQube Scanner:

  * Name: `SonarQubeScanner`
  * Install automatically ✅

---

## 🔸 STEP 7: Configure Maven (if using Java)

* Add Maven:

  * Name: `Maven3`

---

# 🔹 6. Complete Jenkinsfile (End-to-End)

```groovy
pipeline {
    agent any

    tools {
        maven 'Maven3'
    }

    environment {
        SONAR_HOME = tool 'SonarQubeScanner'
    }

    stages {

        stage('Checkout Code') {
            steps {
                echo "Cloning repository..."
                git 'https://github.com/your-repo.git'
            }
        }

        stage('Build') {
            steps {
                echo "Building application..."
                sh 'mvn clean compile'
            }
        }

        stage('Unit Test') {
            steps {
                echo "Running tests..."
                sh 'mvn test'
            }
        }

        stage('SonarQube Analysis') {
            steps {
                echo "Running SonarQube analysis..."
                withSonarQubeEnv('sonarqube') {
                    sh '''
                    mvn sonar:sonar \
                    -Dsonar.projectKey=my-app \
                    -Dsonar.host.url=$SONAR_HOST_URL \
                    -Dsonar.login=$SONAR_AUTH_TOKEN
                    '''
                }
            }
        }

        stage('Quality Gate') {
            steps {
                echo "Checking Quality Gate..."
                timeout(time: 5, unit: 'MINUTES') {
                    waitForQualityGate abortPipeline: true
                }
            }
        }

        stage('Package') {
            steps {
                echo "Packaging application..."
                sh 'mvn package'
            }
        }

        stage('Deploy') {
            steps {
                echo "Deploying application..."
                echo "Deploy step here (Docker/K8s/etc)"
            }
        }
    }

    post {
        success {
            echo "Pipeline Passed ✅"
        }
        failure {
            echo "Pipeline Failed ❌"
        }
    }
}
```

# 🔹 8. Webhook Configuration (MANDATORY)

👉 In SonarQube:

* Go to:

  ```
  Administration → Webhooks
  ```

Add:

```text
http://<JENKINS-URL>/sonarqube-webhook/
```

👉 Required for:

```groovy
waitForQualityGate
```

---

# 🔹 9. End-to-End Flow (Final)

```text
1. Developer pushes code
2. Jenkins triggers pipeline
3. Code is built & tested
4. Sonar Scanner runs
5. Report sent to SonarQube
6. SonarQube analyzes
7. Quality Gate evaluated
8. Webhook notifies Jenkins
9. Pipeline passes/fails
10. Deployment happens
```
