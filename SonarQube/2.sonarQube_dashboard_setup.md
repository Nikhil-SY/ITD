# 🔹 1. Architecture (What we’ll build)

```text
EC2 (Ubuntu)
 ├── SonarQube Server (port 9000)
 └── PostgreSQL (local or managed)
```

👉 You’ll access:

```text
http://<EC2-Public-IP>:9000
```

---

# 🔹 2. Step 1: Launch EC2 Instance

---

## 🔸 Recommended Config

* AMI: **Ubuntu 22.04**
* Instance Type: **t3.medium (minimum)**
  👉 SonarQube needs RAM (avoid t2.micro)

---

## 🔸 Security Group (VERY IMPORTANT)

Add inbound rules:

| Type | Port | Source    |
| ---- | ---- | --------- |
| SSH  | 22   | Your IP   |
| HTTP | 9000 | 0.0.0.0/0 |

👉 This allows browser access

# 🔹 5. Step 4: Install PostgreSQL

---

```bash
sudo apt install postgresql postgresql-contrib -y
```

---

## 🔸 Start Service

```bash
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

---

## 🔸 Create DB & User

```bash
sudo -u postgres psql
```

Inside PostgreSQL:

```sql
CREATE DATABASE sonarqube;
CREATE USER sonar WITH ENCRYPTED PASSWORD 'sonar123';
ALTER ROLE sonar SET client_encoding TO 'utf8';
ALTER ROLE sonar SET default_transaction_isolation TO 'read committed';
ALTER ROLE sonar SET timezone TO 'UTC';
GRANT ALL PRIVILEGES ON DATABASE sonarqube TO sonar;
\q
```

---

# 🔹 6. Step 5: Download SonarQube

---

```bash
wget https://binaries.sonarsource.com/Distribution/sonarqube/sonarqube-9.9.0.65466.zip
unzip sonarqube-*.zip
cd sonarqube-*
```

---

# 🔹 7. Step 6: Configure SonarQube

---

## 🔸 Edit config file

```bash
sudo nano conf/sonar.properties
```

---

## 🔸 Add DB config

```properties
sonar.jdbc.username=sonar
sonar.jdbc.password=sonar123
sonar.jdbc.url=jdbc:postgresql://localhost:5432/sonarqube
```

---

# 🔹 8. Step 7: Fix System Limits (CRITICAL)

---

```bash
sudo nano /etc/sysctl.conf
```

Add:

```bash
vm.max_map_count=262144
fs.file-max=65536
```

---

Apply:

```bash
sudo sysctl -p
```

---

## 🔸 Update limits

```bash
sudo nano /etc/security/limits.conf
```

Add:

```bash
sonar   -   nofile   65536
sonar   -   nproc    4096
```

# 🔹 13. Step 12: (Optional but Important) Run as Service

---

```bash
sudo nano /etc/systemd/system/sonarqube.service
```

Add:

```ini
[Unit]
Description=SonarQube service
After=network.target

[Service]
Type=forking
ExecStart=/home/ubuntu/sonarqube/bin/linux-x86-64/sonar.sh start
ExecStop=/home/ubuntu/sonarqube/bin/linux-x86-64/sonar.sh stop
User=sonar
Group=sonar
Restart=always

[Install]
WantedBy=multi-user.target
```

---

## 🔸 Enable service

```bash
sudo systemctl daemon-reexec
sudo systemctl daemon-reload
sudo systemctl enable sonarqube
sudo systemctl start sonarqube
```
