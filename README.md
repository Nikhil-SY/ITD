# ITD - Infrastructure, Tools & DevOps

A comprehensive repository containing notes, commands, scripts, and resources for DevOps, cloud infrastructure, and development tools.

## 📋 Repository Overview

This repository consolidates knowledge and practical implementations related to DevOps practices, cloud infrastructure, and development tools. It serves as a learning resource and reference guide for DevOps professionals and developers.

### Language Composition
- **Python**: 82.1% - Core scripting and automation
- **Shell**: 14.2% - System and deployment scripts
- **Roff**: 3.7% - Documentation formatting

## 📁 Folder Structure

### [AWS](./AWS)

### [Docker](./Docker)
Comprehensive guides, configurations, and best practices for containerization using Docker.

Notes and commands related to Git version control for effective source code management.

### [Github Actions](./Github%20Actions)
CI/CD workflows and automation using GitHub Actions for continuous integration and deployment.

### [Jenkins](./Jenkins)
